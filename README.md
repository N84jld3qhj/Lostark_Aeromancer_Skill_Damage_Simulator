# 🌩️ 로스트아크 기상술사 시뮬레이터 연산 헬퍼 (Lopec)

[lopec.kr](https://lopec.kr) 캐릭터 시뮬레이터에서 기상술사(질풍노도)의 세팅 상태를 실시간으로 파악하여 스킬 데미지 연산 및 세팅 간 비교 분석을 도와주는 Tampermonkey 확장 스크립트입니다.

* 제공되는 모든 계산 데이터와 로직은 인게임 데이터 및 시뮬레이터 수치를 바탕으로 검증되었으나, 지속적인 기능 개선 및 업데이트를 진행하고 있습니다.

## ✨ 주요 기능 (Features)

* **🌀 실시간 스킬 데미지 계산**
  * 세팅을 실시간으로 감지하여 실시간으로 스킬별 데미지 계산 결과를 보여줍니다.
* **📊 비교군 저장 및 세팅 비교 모달**
  * **[📌 비교군 저장]**: 현재 세팅의 연산 결과를 기준점(Baseline)으로 저장합니다.
  * **[📊 비교표 보기]**: 세팅 변경 후 클릭 시 기존 세팅 대비 데미지 증감 수치를 한눈에 비교할 수 있습니다.
* **🎯 파티 치명타 적중률 시너지 계산**
  * 본인을 제외한 파티원의 치적 시너지 수치(0명 / 1명 / 2명)를 선택하여 치명타 반영 데미지 기댓값을 정밀하게 계산합니다.
* **⏸️ 실시간 연산 토글 (ON / OFF)**
  * 시뮬레이터 세팅 변경 중 렉을 방지하기 위해 실시간 연산을 언제든지 일시정지하거나 다시 켤 수 있습니다.
* **📁 아크패시브 세팅 관리 모달**
  * 다양한 아크패시브 조합 프리셋을 빠르게 확인하고 관리할 수 있습니다.

## 💡 사용 방법 (How to Use)

1. **시뮬레이터 접속**: [lopec.kr](https://lopec.kr/) 캐릭터 검색 후 시뮬레이터 페이지로 이동합니다.
2. **세팅 감지 확인**: 화면 좌측 하단 플로팅 패널 최상단의 뱃지(`🌀 기류 조절` 또는 `⚔️ 비연참`)가 현재 내 질서 코어 세팅과 일치하는지 확인합니다.
3. **시너지 설정**: 파티원 치적 시너지(본인 제외 10%/20%) 보유 상황을 선택합니다.
4. **비교 분석**:
   * 현재 기본 세팅에서 **[📌 비교군 저장]** 클릭
   * 보석, 질서 코어 포인트, 아크패시브 등을 수정
   * **[📊 비교표 보기]**를 눌러 세팅 전환 시의 딜량 변화폭 확인

## ⚠️ 사용 시 유의사항 (Important Notes)

1. **지원하는 질서 코어 세팅 제한**
   * 현재 **비연참(`111`)** 및 **기류 조절(`221`)** 세팅만 연산을 지원합니다.
   * **질서의 해 코어**를 기준으로 세팅을 자동 판별하여 스킬 트라이포드를 스위칭합니다.
   * 해 코어 기준으로 판별하기 때문에 다른 조합을 착용하더라도 `111` 또는 `221` 중 하나로 연산됩니다. *(ex. `123` 조합을 착용하더라도 `111`로 계산)*

2. **트라이포드 수동 변경 미지원**
   * 현재 트라이포드 커스텀 수동 변경 기능은 미구현 상태입니다. 감지된 코어 세팅에 맞춰 고정된 트라이포드로 자동 연산됩니다.

3. **일부 아크 패시브 노드 연산 제외**
   * 실전에서 일반적으로 사용하지 않는 아래 노드들은 계산식에서 제외됩니다:
     > `특화`, `제압`, `인내`, `숙련`, `금단의 주문`, `축복의 여신`, `일격`, `정열의 춤사위`, `선각자`, `진군`, `기원`, `뭉툭한 가시`, `인파이팅`, `마나 용광로`, `안정된 관리자`

4. **기본 캐릭터 스탯 가정**
   * **내실**: 모든 내실 수치는 **최대치**로 반영하여 계산합니다.
   * **펫 버프**: **신속** 을 기본 전제로 연산합니다.
5. **에스더 무기는 계산할 수 없습니다**
   * 빠르게 추가하도록 하겠습니다
