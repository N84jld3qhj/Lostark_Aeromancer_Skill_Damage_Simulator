## 📖 데이터 작성 가이드 (Data Creation Guide)

효율적인 데이터 생성을 위해 **[질서 코어 ➔ 직업 특화 ➔ 고유 버프/스탯 ➔ 스킬]** 순서로 진행하는 것을 권장합니다.  
앞선 3개 단계에서 설정한 **'적용 조건/대상 태그'**들을 미리 정리해 두면, 마지막 스킬 작성 시 태그 누락 없이 정확하게 매칭시킬 수 있습니다.

**`데이터생성.html`** 파일을 사용해 데이터를 만드실 수 있습니다.

---

### 1️⃣ 질서 코어 (아크그리드) 데이터 작성


* 탭 메뉴: `☀️🌙⭐ 질서 코어 생성기`

<img src="https://github.com/N84jld3qhj/Lostark_Skill_Damage_Simulator/blob/140451a34690a43935642aba57f87fb9a8d477ff/images/0000.png" style="border: 1px solid #cccccc;">
각 질서 코어(해/달/별) 노드의 단계별 효과를 입력합니다.

1. **코어 종류 선택**: `해`, `달`, `별` 중 선택합니다.

2. **그룹 아이디 (Group ID)**: 노드 그룹 구분이 필요한 경우 입력합니다. (선택 사항, 빈칸 가능)

그룹 아이디는 코어 내에서 '합연산'이 필요한 데이터가 있을 때 사용합니다.  
<img src="https://github.com/N84jld3qhj/Lostark_Skill_Damage_Simulator/blob/016f6bb9b5ef85080d0cbdc16a4f70aab6701917/images/0010.png?" width=50%>
예를들어 '바람의 칼날' 코어는 14P와 17P가 합연산으로 계산됩니다.  
이러한 경우 그룹 아이디에 같은 아이디를 입력해야 합연산으로 계산됩니다.  
입력할 때 17P 증가량을 따로 계산해서 입력하실 필요 없습니다. 바람의 칼날의 경우 14P에 25% 17P에 44% 입력 하시면 됩니다.
그룹 아이디 없이 입력 시 곱연산이 되어 바람의 칼날은 44%의 데미지 증가가 아니라 25%와 44%가 곱연산으로 적용되어 계산에 오류가 생깁니다.
그룹 아이디 이름은 아무거나 해도 상관 없습니다. 합연산이 되는 것들이 이름이 같기만 하면 됩니다.

3. **노드 포인트 선택**: 
   * `10pt`, `14pt`, `18~20pt`: 고대/유물 공통 수치 자동 생성
   * `17pt`: 고대 수치와 유물 수치를 각각 분리하여 입력

4. **세부 효과 및 조건 태그 입력**:
   * 스탯/피해 범주 선택 후 수치 입력
   * 한번에 여러 개의 카테고리의 효과가 들어간다면 **세부 효과 추가**로 다 넣어 주셔야 합니다. 
   * **적용 조건 태그**: 특정 스킬이나 스킬 그룹에만 적용되는 효과라면 해당 스킬의 태그를 입력합니다. (예: `칼바람`,`타대`, `우산` )
   * **제외 조건 태그**: 특정 스킬이나 스킬 그룹을 제외해야하는 경우 제외 태그를 입력합니다.
   * 💡 *팁: 여기서 입력한 조건 태그를 메모해 두세요!*

---

### 2️⃣ 직업 특화 설정

* 탭 메뉴: `🎨 직업 특화 설정`

<img src="https://github.com/N84jld3qhj/Lostark_Skill_Damage_Simulator/blob/140451a34690a43935642aba57f87fb9a8d477ff/images/0002.png" style="border: 1px solid #cccccc;">

직업의 특화 스탯이 특정 스킬 계수에 주는 영향을 설정합니다.

1. **특화 계수 (Specialization Coefficient)**: 특화 계수를 입력합니다. 
   특화 계수는 특화 수치 699일 때 캐릭터 정보창에 표기되는 값으로 **인게임 정보창 특화 효과x6.99/특화수치**로 계산할 수 있습니다.
   예를들어 특화가 1854일 때 인게임 정보창에서 특화 데미지 증가 수치가 88.05%라면 특화 계수는 88.05*6.99/1854=0.3319 입니다.
   
   특화 계수는 클뜯 데이터를 찾을 수 있어서 특화 계수 파일에 정리해놨습니다.
   
2. **적용 스킬 태그**: 특화 데미지 증가 효과를 받는 스킬 태그들을 쉼표(`,`)로 구분하여 입력합니다. (예: `우산`, `급습`, `랜스`)
3. **[💾 특화 설정 저장]** 버튼을 눌러 반영합니다.

---

### 3️⃣ 고유 버프 / 스탯 작성

* 탭 메뉴: `🛡️ 고유 버프 / 스탯 생성기`

<img src="https://github.com/N84jld3qhj/Lostark_Skill_Damage_Simulator/blob/140451a34690a43935642aba57f87fb9a8d477ff/images/0003.png" style="border: 1px solid #cccccc;">

기본 스탯, 캐릭터 시너지, 펫 효과,아크 패시브 깨달음 등 캐릭터에 적용되는 고유 버프 정보를 입력합니다.

1. **버프 / 스탯명**: 버프의 이름을 입력합니다. (예: `깨달음 - 질풍노도`, `사이드 노드 - 바람의 길`). 원하는 스타일로 입력하시면 됩니다.

2. **세부 효과 추가**:
   * 효과 범주(치명타 적중률, 공격력 %, 쿨타임 감소 등)와 수치를 입력합니다.
   * **적용 스킬 태그**: 해당 버프가 특정 스킬군에만 들어가는 경우 태그를 작성합니다. (비워둘 경우 캐릭터 전체 적용)

3. **[+ 버프 / 스탯 목록에 추가]** 버튼을 클릭합니다.

---

### 4️⃣ 스킬 데이터 작성

* 탭 메뉴: `⚡ 스킬 데이터 생성기`

<img src="https://github.com/N84jld3qhj/Lostark_Skill_Damage_Simulator/blob/140451a34690a43935642aba57f87fb9a8d477ff/images/0004.png" style="border: 1px solid #cccccc;">

앞서 작성한 **질서 코어, 특화, 버프에서 사용했던 태그들을 포함**하여 최종 스킬 데이터를 구성합니다.

1. **기본 정보 입력**: `스킬명`, `상수(Constant)`, `계수(Coefficient)`, `기본 쿨타임(초)`, `마나 소모량`을 입력합니다.   
`마나 소모량`의 경우 마나 용광로를 사용하지 않는 경우 입력하지 않아도 상관은 없습니다.

**모션 상수**와 **모션 계수**를 입력해야 하는데 로스트아크 스킬 데미지는 **모션 상수 + (공격력 x 모션 계수)** 로 계산됩니다.  
자세한 내용은 https://www.inven.co.kr/board/lostark/4821/109679 이걸 참고해주시고  
모션 상수는 **공격력이 0일 때의 스킬 툴팁 표기 데미지** 입니다.  
장비, 장신구, 코어, 젬을 전부 빼고 캐릭터 정보창에 공격력이 0인걸 확인 후 스킬창에서 툴팁을 확인해서 입력해주시면 됩니다. 모션 상수는 인벤 스킬 정보에서도 확인 가능합니다.  
모션 계수는 **(공격력이 n일 때의 스킬 툴팁 표기 데미지 - 모션 상수) ÷ 공격력 n** 으로 구할 수 있습니다.
사용하는 스킬 레벨에 맞춰서 모션 상수와 모션 계수를 찾아서 입력하시면 됩니다.

2. **태그 입력 (중요 🌟)**:

   * 계산시 데이터의 적용 여부를 **태그**를 사용해서 하고 있습니다. 예를들어 계산식에서 **`백어택` 스킬 데미지 증가** 인 경우 `백어택` 태그가 있는 스킬에만 적용됩니다. 
   * **첫 번째 태그는 반드시 스킬 이름**으로 작성합니다. 
   * 1~3단계에서 정리해 둔 **조건 태그(예: `스킬명`, `백어택`, `마나`,`우산`, `기상` 등)가 빠짐없이 포함되었는지 확인**합니다.
   * 기본적으로 필요한 태그는 `마나`(마나 사용 여부) `백어택` `헤드어택` `타대` 이 4가지 입니다. 이 4가지는 아크 패시브 계산에 필요하기 때문에 반드시 넣어주셔야 합니다.

3. **트라이포드 추가**:
   * 각 티어(1/2/3티어)별 트라이포드 이름과 세부 효과를 등록합니다.
   * 하나의 트라이포드에 2가지 이상의 효과가 있는 경우 세부 효과 추가를 통해 2개 이상의 효과를 하나의 트라이포드에 적용할 수 있습니다.

4. **[+ 스킬 목록에 추가]** 버튼을 클릭하여 저장합니다.

# ✨ 주요 기능 (Features)

* **🌀 실시간 스킬 데미지 계산**
  * 세팅을 실시간으로 감지하여 실시간으로 스킬별 데미지 계산 결과를 보여줍니다.
* **📊 비교군 저장 및 세팅 비교 모달**
  * **[📌 비교군 저장]**: 현재 세팅의 연산 결과를 기준점(Baseline)으로 저장합니다.
  * **[📊 비교표 보기]**: 세팅 변경 후 클릭 시 기존 세팅 대비 데미지 증감 수치를 한눈에 비교할 수 있습니다.
* **🎯 파티 치명타 적중률 시너지 계산**
  * 본인을 제외한 파티원의 치적 시너지 수치(0명 / 1명 / 2명)를 선택하여 치명타 반영 데미지 기댓값을 정밀하게 계산합니다.
* **⏸️ 실시간 연산 토글 (ON / OFF)**
  * 시뮬레이터 세팅 변경 중 렉을 방지하기 위해 실시간 연산을 언제든지 일시정지하거나 다시 켤 수 있습니다.
* **📁 아크패시브 세팅 관리 모달**
  * 다양한 아크패시브 조합 프리셋을 빠르게 확인하고 관리할 수 있습니다.

## 💡 사용 방법 (How to Use)

1. **시뮬레이터 접속**: [lopec.kr](https://lopec.kr/) 캐릭터 검색 후 시뮬레이터 페이지로 이동합니다.
2. **데이터 세팅**: 화면 좌측 하단 플로팅 패널 최상단에서 데이터를 불러와 저장합니다. 한번 불러온 적이 있다면 자동으로 로컬 스토리지에 저장됩니다.
3. **계산 시작**: 계산 시작 버튼을 누르면 자동으로 실시간 계산이 시작됩니다. 버튼을 다시 누르면 실시간 계산이 중단됩니다.
4. **비교 분석**:
   * 현재 기본 세팅에서 **[📌 비교군 저장]** 클릭
   * 보석, 질서 코어 포인트, 아크패시브 등을 수정
   * **[📊 비교표 보기]**를 눌러 세팅 전환 시의 딜량 변화폭 확인

## ⚠️ 사용 시 유의사항 (Important Notes)

1. **입력된 데이터만을 사용해서 계산합니다.**
   * 스킬 트라이포드를 바꾸거나 코어를 바꾸기 위해서는 데이터를 직접 수정해서 다시 로드해야합니다.
2. **기본 적인 세팅은 고정으로 입력된 값을 사용합니다.**
   * 능력치 증가 물약, 원정대 레벨, 전투 레벨, 카드 도감, 만찬, 펫목장, 전설 아바타 등 공통으로 들어가는 요소들은 최대치를 기준으로 계산합니다.
3. 특별한 계산식이 필요한 경우는 아직 계산식을 지원하지 않습니다.  
   예를들어 '기상술사 깨달음 기민함'이나 '워로드 깨달음 건랜스 수련' 처럼 특별한 계수(이동 속도, 공격 속도, 치명타 적중률 등)가 필요한 계산식은 아직 지원하지 않습니다.  \
   고유 버프/스탯 입력 시 고정된 값을 입력해서 사용해주세요.
